Prefill vs Decode
System prompt dirakit sekali (prefill paralel), generasi token berjalan autoregresif untuk efisiensi latensi.
Semantic Cache
Jarak cosine < 0.1 ( >90% mirip) langsung balas instan tanpa panggil LLM.
Memori Percakapan
Simpan 10 pesan terakhir per conversation_id untuk dialog multi-turn yang koheren.

Deployment

Langkah 1-3: Siapkan Server openSUSE

Instalasi Docker dan persiapan sumber daya pada openSUSE Tumbleweed/Leap
Langkah 1 — Perbarui sistem
$ sudo zypper refresh && sudo zypper update
Langkah 2 — Pasang Docker + Compose
$ sudo zypper install docker docker-compose
$ sudo systemctl enable --now docker
$ sudo usermod -aG docker $USER # login ulang agar grup berlaku
Langkah 3 — Cek sumber daya
$ free -h && df -h /
$ docker --version && docker compose version
✔ Docker siap digunakan
Prasyarat
openSUSE Tumbleweed/Leap
RAM ≥ 2 GB free
Disk ≥ 4 GB kosong
Akses internet (HuggingFace)
Catatan
Pastikan user berada di grup docker agar tidak perlu sudo saat menjalankan docker compose.

Langkah 4-6: Deploy & Aktifkan LLM

Eksekusi docker compose dengan profile llm untuk inferensi lokal
Langkah 4 — Ambil konfigurasi
$ mkdir raksa-ai && cd raksa-ai
$ curl -O https://raw.githubusercontent.com/.../docker-compose.hub.yml
Langkah 5 — Atur environment (.env)
# Set password DB, LLAMA_CTX, LLAMA_THREADS, TELEGRAM_* (opsional)
Langkah 6 — Jalankan stack
$ docker compose -f docker-compose.hub.yml --profile llm up -d
# Tanpa --profile llm backend tetap jalan, tetapi llama_ready=false
# dan fitur AI nonaktif.

Integrasi Enterprise & Cloud

Agentic-AI-Knowledge-ERP
github.com/Muhammad-Ikhwan-Fathulloh/Agentic-AI-Knowledge-ERP
Ekspansi pipeline agentic untuk Enterprise Resource Planning. LLM berinteraksi dengan knowledge base internal perusahaan, menjawab query kompleks, dan mengotomatisasi task administratif berbasis data ERP.
✓
Knowledge Base ERP: Ingest manual SOP, data transaksi, dan dokumen kebijakan ke pgvector.
✓
Agent Task Automation: Agen merancang rencana penyelesaian untuk proses seperti pembuatan laporan atau validasi data.
✓
Natural Language Query: Eksplorasi database ERP menggunakan bahasa manusia yang aman dan terstruktur.
Pelajari: github.com/Muhammad-Ikhwan-Fathulloh/Agentic-AI-Knowledge-ERP
Raksa-Cloud
github.com/Muhammad-Ikhwan-Fathulloh/Raksa-Cloud
Platform manajemen perangkat IoT dan edge computing. Menyediakan infrastruktur untuk mendaftarkan perangkat, mengelola aktuator, dan melakukan analitik data sensor secara terpusat dengan integrasi ML.
✓
Device Management: API untuk pendaftaran dan pemantauan status perangkat IoT (ESP32) secara real-time.
✓
TinyML Integration: Menyinkronkan model machine learning ringan ke edge device untuk inferensi lokal.
✓
Data Pipeline: Pengumpulan telemetry terstandar untuk dashboarding dan pelatihan model anomaly detection.
Pelajari: github.com/Muhammad-Ikhwan-Fathulloh/Raksa-Cloud
