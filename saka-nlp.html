# 2. Emoji → teks Indo (3,800+ emoji)

# 900+

Studi Kasus #2

Heuristic Morphology Analyzer

Bukan sekadar stem - analisis morfologi lengkap dengan morphophonemic & validasi daerah

python import saka

# Kata majemuk + afiks luluh
print(saka.analyze("menyebarluaskan"))

# {'root': 'sebar luas',
# 'prefixes': ['meny'],
# 'suffixes': ['kan'],
# 'type': 'unknown',
# 'regional_matches': []}

# Early Stopping → bahasa daerah!
print(saka.analyze("dipikanyaah"))

# {'root': 'nyaah',
# 'prefixes': ['dipika'],
# 'suffixes': [],
# 'type': 'regional',
# 'regional_matches': ['sunda']}
1

Prefix + Suffix Detection

meny- + -kan → mendeteksi peleburan "s" ke "y" (morphophonemic)

2

Compound Word Recovery

"sebarluaskan" → root "sebar luas" - mempertahankan semantik kata majemuk serangkai

3

Early Stopping → Regional

"dipikanyaah" → berhenti di "nyaah" (Sunda), bukan terus memotong sampai kosong

vs Sastrawi: Sastrawi hanya suffix-stripping. Tidak ada morphophonemic, tidak ada compound word, tidak ada validasi daerah.

Studi Kasus #4

Agentic AI & Structured Prompting

Multi-Agent Orchestration + Dynamic Tool Calling - langsung dari saka

python from saka import MultiAgentManager, Agent

# --- Multi-Agent Orchestration ---
mgr = MultiAgentManager()
mgr.add_agent("math", "Alih Matematika",
  "Selesaikan soal kalkulus.")
mgr.add_agent("science", "Ahli Sains",
  "Selesaikan soal fisika.")

prompt = mgr.route_prompt(
  "Soal tentang gravitasi"
)

# --- Dynamic Tool Calling ---
bot = Agent("Asisten Nilai",
  "Cek nilai siswa.")
bot.add_tool(
  name="get_grade",
  desc="Ambil nilai",
  params={"name": "string"},
  func=lambda n: f"Nilai {n}: 90"
)
res = bot.call_tool("get_grade",
  {"name": "Budi"})
# "Nilai Budi: 90"
