02 · Ide lightweight

Ringan berarti tiga lapis

Lapis 1 · Aturan dan leksikon

Morfologi, slang, dan stopword berasal dari aturan dan kamus yang bisa dibaca dan diaudit. Tidak ada bobot model yang harus diunduh.

Lapis 2 · Modul kecil

Setiap komponen (tokenizer, normalizer, analyzer, stopwords, KBBI, aksara) bisa dipakai sendiri. Tidak ada pipeline monolitik.

Lapis 3 · Efisien saat dipakai ulang

Hasil normalize(), analyze(), dan get_stopwords() di-cache LRU. Pemrosesan banyak teks bisa asinkron.

Fitur 1 dari 13 · Fondasi

Tokenisasi dan normalisasi

Apa itu

Tokenisasi memecah teks menjadi token: kata, angka, tanda baca, URL, mention, hashtag, dan emoji. Normalisasi mengubah bahasa gaul menjadi bentuk baku, memakai 1.018 entri slang.

Untuk apa

  • Membersihkan komentar media sosial sebelum dihitung
  • Menyeragamkan kata seperti "klo", "gw", dan "udh"
  • Langkah pertama untuk kuisioner dan esai
import saka

saka.tokenize("Belajar NLP di era 5G, seru banget!")
# ['Belajar','NLP','di','era','5G',',','seru','banget','!']

saka.normalize("klo gimana ntar gw k kampus")
# 'kalau bagaimana nanti saya ke kampus'
Inputklo gimana ntar gw k kampus
→
normalize()kalau bagaimana nanti saya ke kampus
→
tokenize()token per kata, angka, dan tanda baca

Fitur 2 dari 13 · Performa

Pemrosesan asinkron

Apa itu

Metode async_* berbasis asyncio. Beberapa teks diproses bersamaan, tanpa menunggu satu tugas selesai dulu.

Untuk apa

  • Memproses ribuan komentar kuisioner sekaligus
  • Menggabungkan pemrosesan teks dengan panggilan jaringan, seperti KBBI atau scraping
  • Menjaga aplikasi web tetap responsif saat ada batch besar
import asyncio, saka

async def main(daftar_kata):
    # Permintaan dikirim bersamaan
    hasil = await asyncio.gather(
        *[saka.query_sastra(k) for k in daftar_kata])
    return hasil

asyncio.run(main(["mangan", "ajar"]))

Ilustrasi konsep. Waktu nyata bergantung pada beban kerja dan I/O.

Optimasi performa dengan cache

Apa itu

Cache LRU (Least Recently Used) pada normalize(), analyze(), dan get_stopwords(). Input yang sama tidak dihitung ulang.

Untuk apa

  • Kata dan slang yang muncul ribuan kali dalam satu batch
  • Stopword yang dipanggil untuk setiap dokumen
  • Menghemat waktu tanpa mengubah hasil

Fitur 5 dari 13 · Morfologi

Penganalisis morfologi

Apa itu

Analisis afiks secara hibrida: prefiks dan sufiks, restrukturisasi morfofonemik (misalnya s yang melebur menjadi y), dan kata majemuk. Hasilnya berupa dictionary berisi root, prefixes, suffixes, type, dan regional_matches.

Untuk apa

  • Menggabungkan bentuk turunan ke akar kata untuk fitur yang lebih padat
  • Membedakan kata baku dari kata daerah
  • Membantu analisis esai, misalnya variasi bentuk kata
import saka

r = saka.analyze("mempertanggungjawabkan")
r["root"]     # 'tanggung jawab'

saka.analyze("menyebarluaskan")["root"]
# 'sebar luas'
Katamenyebarluaskan
→
Afiksprefiks meny-, sufiks -kan
→
Morfofonemikpulihkan bunyi yang melebur
→
Rootsebar luas

Stemmer biasa (Sastrawi) hanya memotong sufiks. Saka menambah prefiks, morfofonemik, dan validasi kata majemuk.

Fitur 7 dari 13 · Kamus

KBBI langsung

Apa itu

Scraper real-time ke KBBI Daring (Kemendikdasmen). Fungsi query_kbbi() mengembalikan status dan daftar definisi.

Untuk apa

  • Mengecek apakah sebuah kata ada di KBBI, misalnya dalam esai

Butuh koneksi internet. Hasil bergantung pada ketersediaan situs sumber.

03 · Pipeline

Fitur dirangkai menjadi satu alur

Teks mentahkuisioner, esai, atau komentar
→
normalize()bahasa gaul ke baku
→
tokenize()pecah token
→
get_stopwords()buang kata fungsi
→
analyze()akar kata dan leksikon daerah
import saka

def preprocess(teks):
    teks = saka.normalize(teks)
    stops = saka.get_stopwords("id")
    return [t for t in saka.tokenize(teks)
            if t.lower() not in stops]

preprocess("klo gimana ntar gw k kampus")

Hasil akhirnya dipakai untuk

  • Fitur untuk model klasik (TF-IDF, Naive Bayes, SVM)
  • Input untuk model neural atau transformers
  • Data untuk agen LLM, lalu diformat dengan OutputFormatter
