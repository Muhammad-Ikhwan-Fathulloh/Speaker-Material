04 / 27Problem
Kenapa Ini Penting?

Sawah, pabrik, dan connectivity gap.

Bayangkan sensor kelembaban tanah di tengah sawah, atau sensor getaran di motor pabrik yang jauh dari jaringan stabil.

Jika setiap pembacaan sensor dikirim mentah ke cloud untuk diproses, kita menghadapi tiga masalah:

01
Latency Tinggi
Setiap request bolak-balik ke cloud menambah delay keputusan kritis.
02
Boros Bandwidth
Mengirim raw data terus-menerus menguras kuota dan daya.
03
Sistem Buta saat Koneksi Putus
Tanpa cloud, device tidak bisa mengambil keputusan apa pun.
Solusi → In-situ Analytics: proses dan ambil keputusan langsung di titik sensor, baru kirim hasil ringkasnya ke cloud. Ini yang disebut Edge Intelligence.

Diciptakan oleh Damien George pada 2013 lewat Kickstarter. Tujuannya: membawa kemudahan dan keterbacaan Python 3 ke dunia mikrokontroler, yang dulu didominasi C/C++.

10 / 27Library Evolution
Dari Kondisi Terbatas → Library Reusable

Dari kode mentah menjadi library.

Menulis inferensi ML di ESP32 dari nol berarti mengurus alokasi memori statis dan operasi matriks manual. Raksa lahir untuk mengabstraksikan kerumitan ini agar mudah dipakai.

FASE 01
Kode Mentah (Raw)
Mengurus malloc statis, loop matriks manual, dan mitigasi fragmentasi memori. Ribuan baris boilerplate yang rentan error dan sulit di-scale.
HARD TO MAINTAIN
FASE 02
Abstraksi Kelas
Logika inferensi dibungkus dalam class KNN atau AnomalyDetector. Developer tidak perlu pusing melihat implementasi pointer atau array di baliknya.
ENCAPSULATED
FASE 03 · RAKSA
Library Terdistribusi
Dikemas menjadi library MicroPython yang bisa di-mip.install(). Siapa pun cukup memanggil .fit() dan .predict() tanpa pusing memikirkan RAM 520KB.
EASY TO USE

12 / 27Optimization · @native
Teknik Optimasi #1

Kenapa @micropython.native?

evaluation.py · defensive import
try:
    import micropython
except ImportError:
    class micropython:
        @staticmethod
        def native(f):
            return f
AnomalyDetector.score()
@micropython.native
def score(self, x):
    max_z = 0.0
    for j in range(self.dims):
        z = abs(x[j] - self.means[j]) / self.stds[j]
        if z > max_z:
            max_z = z
    return max_z
// NORMAL MODE
Interpret baris per baris
Setiap kali loop jalan, interpreter harus parsing ulang bytecode. Lambat untuk kode compute-heavy.
// @native MODE
Compiled to machine code
MicroPython mengkompilasi fungsi langsung jadi native machine code ARM/Xtensa saat load time — overhead interpreter dihilangkan.
Defensive trick: try/except import micropython supaya kode yang sama bisa di-test di laptop (CPython) dan dioptimalkan penuh di ESP32. Satu source, dua environment.

Live Demo #1 · DHT22 Anomaly Detection

Deteksi anomali suhu & kelembaban.

esp32/with_cloud/demo1.py
from raksa import MinMaxScaler, AnomalyDetector
import urequests, network, time, dht, machine

# 1. WiFi Connection
wlan = network.WLAN(network.STA_IF); wlan.active(True)
wlan.connect("Wokwi-GUEST", ""); time.sleep(5)

# 2. Init ML Models (Raksa)
scaler = MinMaxScaler(dims=2, min_vals=[15.0, 20.0], max_vals=[50.0, 95.0])
detector = AnomalyDetector(threshold=2.0)
detector.fit([25.0, 60.0], n_samples=1, dims=2)

# 3. Main Loop
sensor = dht.DHT22(machine.Pin(15))
while True:
    sensor.measure()
    temp, hum = sensor.temperature(), sensor.humidity()
    is_anomaly = detector.detect([temp, hum])

    # 4. Cloud Sync (urequests)
    urequests.post("http://192.168.1.XX:5000/api/telemetry",
        json={"device_id": "ESP32-DHT22-01",
              "raw_data": {"temp": temp, "hum": hum},
              "is_alert": is_anomaly}).close()
    time.sleep(2)
// ML PROCESS
Sensor membaca Suhu & Kelembaban. Data dinormalisasi ke [0.0, 1.0] dan dibandingkan dengan baseline menggunakan rumus Z-Score. Jika Z > threshold, sistem menandainya sebagai anomali (kebakaran/suhu drop).
Z = (|X - μ|) / σ

from raksa import MinMaxScaler, LogisticRegression
import urequests, network, time, machine

# 1. WiFi Connection
wlan = network.WLAN(network.STA_IF); wlan.active(True)
wlan.connect("Wokwi-GUEST", ""); time.sleep(5)

# 2. Init ML Models (Raksa)
scaler = MinMaxScaler(dims=1, min_vals=[0.0], max_vals=[4095.0])
model = LogisticRegression(dims=1, weights=[8.5], bias=-4.25)

# 3. Main Loop
adc = machine.ADC(machine.Pin(34))
while True:
    raw_adc = adc.read()
    scaled = scaler.transform([raw_adc])
    pred = model.predict(scaled)

    # 4. Cloud Sync (urequests)
    urequests.post("http://192.168.1.XX:5000/api/telemetry",
        json={"device_id": "ESP32-AIR-01",
              "raw_data": {"adc": raw_adc},
              "is_alert": bool(pred)}).close()
    time.sleep(1.5)
// ML PROCESS
Supervised Linear Classification. Nilai mentah ADC udara dinormalisasi dan di-feed ke perceptron tunggal logistik. Bobot (W) dan Bias (b) dilatih untuk memisahkan ambang gas kotor.
P(y=1|x) = 1 / (1 + e^-(wX+b))
Edge Inferensi mengklasifikasikan bahaya via Sigmoid. Dashboard menampilkan alert polusi Device 2.
